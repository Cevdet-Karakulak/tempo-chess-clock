# App Review notes

Tempo is an offline two-player board-game timer for iPhone and iPad. No login, review account, purchases, ads or backend is required.

The app opens on the Time controls tab. Choose 3 + 2, then tap the central start button. Tap the active player's clock panel after a move to switch clocks. Clock panels respond to a single tap. While a clock is running, the central reset, pause and settings controls require two taps on the same button within 600 milliseconds to prevent accidental actions. When idle or paused, these controls respond to one tap.

Move Log pauses the clock and lists recorded clock presses and thinking times; it does not record chess notation. Export PDF prepares a local report and opens the iOS share sheet. Export image saves a PNG directly to Photos without leaving Move Log. The first save requests add-only Photos permission; existing photos are not read. Images contain the last 20 presses and the game summary. PDFs contain all retained records, up to 2,000 presses. If Photos permission is declined, clock and PDF features remain available.

Settings > Tournament lets you edit move thresholds and time additions. Settings > Simul provides independent times for exhibition roles; each board uses its own device. There is no remote multiplayer or automatic position analysis.

Settings > Theme contains colors and the finish animation switch. To test the animation, choose a short custom time and let the active clock expire. The clock face and fallen flag remain visible in the finished game. The animation respects the device's Reduce Motion setting.

Settings includes Turkish and English controls. Theme > Privacy and support opens within the settings window. Privacy policy is an offline in-app page; Back returns to support, then Theme. The optional web-version link opens the public policy in the browser. The support email button opens the user's mail app; no message is automatically sent.

The screen stays awake while the app is open. Leaving the foreground or locking the device deliberately pauses play; tap Resume after returning. Preferences, favorites and the last game are stored only on the device. No telemetry or tracking SDK is included.
